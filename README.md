# JustEnoughBlox

JustEnoughBlox is an extension enhances the Roblox experience with QoL features along with a "Seal of Quality" for games.

### Lists
Create private custom lists of Roblox experiences directly on the Roblox website. You can share it or import others lists.

### JEB Seal of Quality
A curated selection of Roblox experiences considered particularly polished or noteworthy by JEB.

The selection and ratings are fetched automatically when you load or refresh a Roblox Charts or game page. No extension reload is needed to receive feed updates. If the feed is unavailable, the last saved selection remains available.
